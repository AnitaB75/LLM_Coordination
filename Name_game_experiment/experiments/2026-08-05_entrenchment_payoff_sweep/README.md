## What it tested

Convention length (j7/j4/j1) crossed with the new option's payoff (M = 15, 20, or 40 vs J = 10; gaps of 1.5x, 2x, 4x). 9 trials per run. Extended with a second sweep on 2026-08-06.

## What it found

Maps where the convention breaks as a function of both how entrenched it is and how much is on offer.
