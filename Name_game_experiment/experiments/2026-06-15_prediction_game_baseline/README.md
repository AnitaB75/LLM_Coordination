# Prediction game - baseline

`2026-06-15` · prediction_game_baseline

## What it tested

gpt-5.4 as an OBSERVER, not a player: shown rounds 1-7 of all-J play by 6 humans, asked to predict rounds 9-14. Six round-8 evidence conditions (0M/1M/2M/3M/4M/splitMN) x 20 runs. Paired with a play-condition run of the same payoff structure.

## What it found

Baseline for the underestimation hypothesis - does an LLM expect humans to hold the J convention longer than they actually do?
