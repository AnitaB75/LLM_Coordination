# Convention entrenchment - pilot (M/N)

`2026-08-04` · entrenchment_pilot

## What it tested

Does the number of J-only rounds BEFORE an unannounced payoff shift determine whether the group abandons J? Conditions j7/j4/j1 (7, 4, or 1 J-only round), post-shift phase held at 7 rounds. Human framing throughout. Both providers, 3 trials.

## What it found

First pass at the entrenchment question; superseded by the singleM variant, which removes the M-vs-N coordination problem.
