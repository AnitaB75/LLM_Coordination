# Convention entrenchment - single-M variant

`2026-08-04` · entrenchment_singleM

## What it tested

Same entrenchment design with ONE high-value letter (M) instead of two (M/N), removing the confound that switching requires agreeing on WHICH new letter. Includes the first payoff sweep.

## What it found

Isolates entrenchment from the M-vs-N coordination problem.
