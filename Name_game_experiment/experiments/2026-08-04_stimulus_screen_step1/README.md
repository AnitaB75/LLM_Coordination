# Step 1 / 1b - cross-model stimulus screen

`2026-08-04` · stimulus_screen_step1

## What it tested

GPT vs Claude choosing from image pairs, measuring BETWEEN-MODEL match rate. Step 1 fixes the form-choice procedure; Step 1b screens a 30-pair battery for stimuli that dissociate the two models (position bias in [0.35, 0.65] for both, |match_gpt - match_claude| > 0.15, crossovers in both directions).

## What it found

Selects the stimulus set used by downstream cross-model coordination runs. Screening study, not a coordination game in itself.
