Game Overview

You will be in a group of {{ total_players }} players. Each round, all {{ total_players }} players choose a letter. Your goal as a group is to all choose the same letter.

How It Works

  1. All {{ total_players }} players choose their letters simultaneously each round
  2. After each round, you see the results showing ALL {{ total_players }} players' choices and whether you matched
  3. You earn points ONLY if all {{ total_players }} players chose the same letter
  4. Continue to the next round with the same group
